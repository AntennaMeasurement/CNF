# Antenna Measurement CNF

A Python package for antenna measurement CNF utilities.

## Installation

```bash
pip install antenna-measurement-cnf
```

## Usage

As a library:

```python
from antenna_measurement_cnf import hello

hello()  # prints "Hello"
```

As a command line tool:

```bash
AntennaMeasurementCNFCli
```

## Development

```bash
pip install -e .[test]
pytest
```
